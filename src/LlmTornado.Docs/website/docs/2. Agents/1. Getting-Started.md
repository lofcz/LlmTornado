# Getting started with Agents

`LlmTornado.Agents` adds an agent loop on top of the core Chat and Responses APIs. A `TornadoAgent` combines a provider client, model, instructions, tools, and optional structured output.

## Install and configure

```powershell
dotnet add package LlmTornado.Agents
```

```csharp
using LlmTornado;
using LlmTornado.Agents;
using LlmTornado.Chat;
using LlmTornado.Chat.Models;
using LlmTornado.Code;

string apiKey = Environment.GetEnvironmentVariable("OPENAI_API_KEY")
    ?? throw new InvalidOperationException("Set OPENAI_API_KEY first.");

TornadoApi api = new TornadoApi(
    new ProviderAuthentication(LLmProviders.OpenAi, apiKey));

TornadoAgent agent = new TornadoAgent(
    client: api,
    model: ChatModel.OpenAi.Gpt41.V41Mini,
    name: "CSharpHelper",
    instructions: "Answer C# questions concisely.");
```

## Run the agent

`TornadoAgent.Run` is the public convenience method. It delegates to `TornadoRunner.RunAsync`, which manages turns, tool execution, guardrails, cancellation, and events.

```csharp
Conversation result = await agent.Run("What is a primary constructor?");
Console.WriteLine(result.Messages.Last().Content);
```

Agents are stateless between calls unless you pass prior messages back in:

```csharp
result = await agent.Run(
    "Show a short example.",
    appendMessages: result.Messages.ToList());
```

For durable history, use [persistent conversations](/agents/tornado-agent/persistent-conversation).

## Add a function tool

```csharp
using System.ComponentModel;

[Description("Return the current weather for a city")]
string GetWeather([Description("City name")] string city)
{
    return $"The demo forecast for {city} is sunny.";
}

TornadoAgent weatherAgent = new TornadoAgent(
    client: api,
    model: ChatModel.OpenAi.Gpt41.V41Mini,
    instructions: "Use the weather tool when needed.",
    tools: [GetWeather]);

Conversation weather = await weatherAgent.Run("What is the weather in Prague?");
```

Use `toolPermissionHandle` when tool execution requires application or user approval. Do not expose privileged tools without validating their arguments and authorization.

## Stream progress and observe usage

Enable streaming and consume typed runner events with `onAgentRunnerEvent`:

```csharp
using LlmTornado.Agents.DataModels;

ValueTask HandleEvent(AgentRunnerEvents evt)
{
    switch (evt)
    {
        case AgentRunnerStreamingEvent streamingEvent
            when streamingEvent.ModelStreamingEvent is ModelStreamingOutputTextDeltaEvent text:
            Console.Write(text.DeltaText);
            break;

        case AgentRunnerRequestPreparedEvent prepared:
            Console.WriteLine($"Request tokens: {prepared.Tokens.RequestTokensBeforeSend}");
            break;

        case AgentRunnerUsageReceivedEvent usage:
            Console.WriteLine($"Total tokens: {usage.Usage.TotalTokens}");
            break;
    }

    return ValueTask.CompletedTask;
}

await agent.Run(
    "Explain covariance.",
    streaming: true,
    onAgentRunnerEvent: HandleEvent);
```

Preflight token telemetry identifies whether the provider tokenizer or an estimator supplied the count. Provider usage events can include cached, audio, image, reasoning, and tool-use token detail when the provider returns it.

## Control a run

```csharp
using CancellationTokenSource cts = new(TimeSpan.FromSeconds(30));

Conversation controlled = await agent.Run(
    "Review this design.",
    maxTurns: 4,
    runnerOptions: new TornadoRunnerOptions
    {
        TokenLimit = 100_000,
        ThrowOnCancelled = false,
        ThrowOnToolError = true
    },
    cancellationToken: cts.Token);
```

See [Tornado Runner](/agents/tornado-agent/tornado-runner) for all error and cancellation options.
