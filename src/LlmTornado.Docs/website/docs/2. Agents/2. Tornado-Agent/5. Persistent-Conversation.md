# Persistent conversations

Agent conversations can be saved and restored across application restarts. Persistence preserves message roles, text, and supported multipart content.

## Save and resume

```csharp
using LlmTornado.Agents;
using LlmTornado.Chat;

Conversation result = await agent.Run("My preferred language is C#.");

string path = Path.Combine("conversations", "session-123.json");
result.Messages.ToList().SaveConversation(path);

List<ChatMessage> messages = [];
messages.LoadMessages(path);

Conversation resumed = await agent.Run(
    "Which language do I prefer?",
    appendMessages: messages);
```

`SaveConversation` writes a JSON array. `LoadMessages` reads that format synchronously. `PersistentConversation` is the JSONL alternative for append-oriented or continuous saving.

## Continuous JSONL persistence

```csharp
PersistentConversation history = new(
    Path.Combine("conversations", "session-123.jsonl"),
    continuousSave: true);

history.AppendMessage(new ChatMessage(ChatMessageRoles.User, "Remember this message."));

Conversation resumed = await agent.Run(
    "What did I ask you to remember?",
    appendMessages: history.Messages);
```

When `continuousSave` is false, call `SaveChanges()` after appending messages. Constructing `PersistentConversation` with an existing file loads its JSONL messages.

## Images, audio, and documents

When a conversation has a file path, base64 image, audio, and PDF payloads are externalized to a sibling `media` directory. The JSON or JSONL stores a relative `MediaFilePath`; loading reconstructs the corresponding `ChatMessagePart`.

```text
conversations/
|-- session-123.json
`-- media/
    |-- <generated-id>.png
    |-- <generated-id>.wav
    `-- <generated-id>.pdf
```

Remote image, audio, and document URLs remain URLs. Older inline base64 image data remains readable as a fallback.

Treat the conversation file and its `media` directory as one persistence unit:

- Move, copy, back up, and delete them together.
- Keep relative paths intact.
- Apply the same access controls and retention policy to both.
- Validate untrusted media before exposing it to other systems.

`DeleteConversation(path)` removes the conversation file only; clean up the sidecar media directory explicitly when your retention policy permits it.

## Storage guidance

- Use a unique path per conversation.
- Never place secrets in the persisted message history.
- Trim or summarize old messages before they exceed the target model's context window.
- Coordinate writers at the application level; persistence is not a distributed locking system.
- Encrypt sensitive data at rest and enforce per-user authorization.
