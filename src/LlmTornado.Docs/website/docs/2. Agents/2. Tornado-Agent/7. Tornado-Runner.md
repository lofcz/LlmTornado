# Tornado Runner

`TornadoRunner` executes the agent loop: it builds the conversation, checks guardrails, sends model requests, resolves tools, emits events, and stops on completion or a configured limit.

Most applications should call `TornadoAgent.Run`. Call `TornadoRunner.RunAsync` directly when you need the lower-level parameter names or want to construct a run around an existing agent.

## Configure limits and errors

```csharp
TornadoRunnerOptions options = new()
{
    TokenLimit = 120_000,
    SystemMessageAtStart = true,
    ThrowOnMaxTurnsExceeded = true,
    ThrowOnTokenLimitExceeded = true,
    ThrowOnCancelled = false,
    ThrowOnResponseError = true,
    ThrowOnRequestError = true,
    ThrowOnToolError = true
};

Conversation result = await agent.Run(
    "Inspect this design for failure modes.",
    maxTurns: 5,
    runnerOptions: options);
```

The three error flags distinguish provider response failures, internal request-processing failures, and tool failures. Defaults favor returning a partial conversation and emitting events instead of throwing. Set the flags deliberately for your application's reliability policy.

## Cancel a run

The runner accepts a standard `CancellationToken`:

```csharp
using CancellationTokenSource cts = new(TimeSpan.FromSeconds(45));

Conversation result = await agent.Run(
    "Perform a bounded review.",
    runnerOptions: new TornadoRunnerOptions { ThrowOnCancelled = false },
    cancellationToken: cts.Token);
```

You can also call `agent.Cancel()` from another part of the application. Cancellation is observed by the loop and recorded in `agent.LastRunExitReason`. With `ThrowOnCancelled = false`, the runner returns the conversation accumulated so far; with `true`, it throws `OperationCanceledException`.

## Runner events and telemetry

```csharp
ValueTask OnRunnerEvent(AgentRunnerEvents evt)
{
    switch (evt)
    {
        case AgentRunnerRequestPreparedEvent prepared:
            AgentRequestTokenTelemetry tokens = prepared.Tokens;
            Console.WriteLine(
                $"{tokens.RequestTokensBeforeSend}/{tokens.ContextWindowTokens} " +
                $"({tokens.ContextWindowUtilization:P1}, {tokens.Source})");
            break;

        case AgentRunnerUsageReceivedEvent received:
            AgentUsageTelemetry usage = received.Usage;
            Console.WriteLine(
                $"input={usage.PromptTokens}, output={usage.CompletionTokens}, " +
                $"total={usage.TotalTokens}");
            break;

        case AgentRunnerCancelledEvent:
            Console.WriteLine("Agent run cancelled.");
            break;
    }

    return ValueTask.CompletedTask;
}

Conversation result = await agent.Run(
    "Summarize this conversation.",
    onAgentRunnerEvent: OnRunnerEvent);
```

`AgentRunnerRequestPreparedEvent` is emitted before the request when a callback is registered. `AgentRunnerUsageReceivedEvent` reflects provider-reported usage after a response. Detailed fields are nullable because providers return different usage breakdowns.

## Direct runner call

The corresponding lower-level call uses `messagesToAppend` and `runnerCallback`:

```csharp
Conversation result = await TornadoRunner.RunAsync(
    agent,
    input: "Continue the review.",
    maxTurns: 5,
    messagesToAppend: previousMessages,
    runnerCallback: OnRunnerEvent,
    runnerOptions: options,
    cancellationToken: cancellationToken);
```

## Exit state

After a run, inspect `agent.LastRunExitReason` to distinguish completion, cancellation, guardrail triggers, token or turn limits, tool failures, response failures, and request failures. Do not infer success only from the absence of an exception when throw flags are disabled.
