# Codex model routing

> **Provider-specific:** The model names and availability on this page are OpenAI-specific. Confirm account access before choosing a Codex model.

Codex model constants declare Responses and Batch capabilities, not Chat Completions. LlmTornado uses that metadata to route higher-level Chat and Agent requests to the Responses endpoint automatically.

## Use the Responses endpoint directly

This pattern follows the current `ResponsesDemo` coverage:

```csharp
using LlmTornado.Chat;
using LlmTornado.Chat.Models;
using LlmTornado.Responses;

ResponseResult result = await api.Responses.CreateResponse(new ResponseRequest
{
    Model = ChatModel.OpenAi.Codex.Gpt53Codex,
    Reasoning = new ReasoningConfiguration(ResponseReasoningEfforts.Low),
    InputItems = [
        new ResponseInputMessage(
            ChatMessageRoles.User,
            "Write a one-line C# method that adds two integers.")
    ],
    MaxOutputTokens = 512
});

Console.WriteLine(result.OutputText);
```

## Use the higher-level Chat API

No manual URL selection is required. Because the model lacks the Chat capability, `Conversation` upcasts the request to Responses:

```csharp
Conversation conversation = api.Chat.CreateConversation(new ChatRequest
{
    Model = ChatModel.OpenAi.Codex.Gpt53Codex,
    ResponseRequestParameters = new ResponseRequest
    {
        Reasoning = new ReasoningConfiguration(ResponseReasoningEfforts.Low),
        MaxOutputTokens = 512
    }
});

conversation.AddUserMessage("Review this method for edge cases: int Add(int a, int b) => a + b;");
ChatRichResponse response = await conversation.GetResponseRich();
Console.WriteLine(response.Text);
```

`ResponseRequestParameters` carries Responses-specific settings while `Conversation` manages messages and response conversion. Do not force `UseResponseEndpoint = false` for a Responses-only model.

## Continue a Codex response

Direct Responses calls can use `PreviousResponseId` for the next phase:

```csharp
ResponseResult followUp = await api.Responses.CreateResponse(new ResponseRequest
{
    Model = ChatModel.OpenAi.Codex.Gpt53Codex,
    PreviousResponseId = result.Id,
    Reasoning = new ReasoningConfiguration(ResponseReasoningEfforts.Low),
    InputString = "Now add XML documentation comments.",
    MaxOutputTokens = 512
});
```

Codex is not a replacement for executing or testing generated code. Keep tool permissions, cancellation, output limits, and application-level validation in the calling workflow.
