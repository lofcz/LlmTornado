# Custom providers

> **Advanced:** Custom endpoints vary in URL layout and authentication behavior. Verify the endpoint format against the server you operate.

LlmTornado can target self-hosted and OpenAI-compatible services through the `Custom` provider. The base URL and API key can be supplied together or represented by `ProviderAuthentication`.

## Base URL with bearer authentication

```csharp
using LlmTornado;
using LlmTornado.Chat;
using LlmTornado.Chat.Models;
using LlmTornado.Code;

ProviderAuthentication authentication = new(
    LLmProviders.Custom,
    Environment.GetEnvironmentVariable("CUSTOM_LLM_API_KEY") ?? string.Empty)
{
    BaseUrl = "https://models.example.com"
};

TornadoApi api = new TornadoApi(authentication);

Conversation conversation = api.Chat.CreateConversation(new ChatRequest
{
    Model = new ChatModel("your-model-id", LLmProviders.Custom)
});

conversation.AddUserMessage("Hello from a custom endpoint.");
Console.WriteLine((await conversation.GetResponseRich()).Text);
```

For `LLmProviders.Custom`, `BaseUrl` is expanded to `{baseUrl}/{apiVersion}/{endpoint}`. The default API version is `v1`, and the API key is sent as bearer authentication by the OpenAI-compatible endpoint provider.

## URI constructor

The URI constructor is a shorter equivalent when the standard URL template is sufficient:

```csharp
TornadoApi api = new TornadoApi(
    new Uri("https://models.example.com"),
    customApiKey,
    LLmProviders.Custom);
```

If the URI does not contain format tokens, LlmTornado appends `/{0}/{1}`. Use `ApiUrlFormat` when the service needs a different but still format-based path:

```csharp
TornadoApi api = new TornadoApi(authentication)
{
    ApiUrlFormat = "https://models.example.com/openai/{0}/{1}"
};
```

For URL layouts, headers, or protocols that cannot be expressed this way, implement `IEndpointProvider` and pass it to `new TornadoApi(provider)`.

## Endpoints without authentication

Pass an empty API key only when the server intentionally accepts unauthenticated requests:

```csharp
TornadoApi localApi = new TornadoApi(
    new Uri("http://localhost:11434"),
    string.Empty,
    LLmProviders.Custom);
```

Do not embed production keys in source or documentation examples. Prefer environment variables, user secrets, or your deployment platform's secret store.
