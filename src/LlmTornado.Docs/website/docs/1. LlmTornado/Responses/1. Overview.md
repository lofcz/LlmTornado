# Responses API

`TornadoApi.Responses` exposes OpenAI's Responses API for typed input and output items, response chaining, reasoning options, tools, and streaming events. Use it when you need Responses-specific features; use the higher-level Chat API when a conventional multi-provider conversation is enough.

## Create a response

```csharp
using LlmTornado;
using LlmTornado.Chat;
using LlmTornado.Chat.Models;
using LlmTornado.Responses;

TornadoApi api = new TornadoApi(openAiApiKey);

ResponseResult result = await api.Responses.CreateResponse(new ResponseRequest
{
    Model = ChatModel.OpenAi.Gpt41.V41Mini,
    Instructions = "Answer in one short paragraph.",
    InputItems = [
        new ResponseInputMessage(ChatMessageRoles.User, "Explain records in C#.")
    ],
    MaxOutputTokens = 300
});

Console.WriteLine(result.OutputText);
```

`CreateResponse` throws when the HTTP request fails. `CreateResponseSafe` returns an `HttpCallResult<ResponseResult>` when the application needs to inspect failures without an exception.

## Continue from an earlier response

Set `PreviousResponseId` to chain a new turn to a stored response:

```csharp
ResponseResult followUp = await api.Responses.CreateResponse(new ResponseRequest
{
    Model = ChatModel.OpenAi.Gpt41.V41Mini,
    PreviousResponseId = result.Id,
    InputItems = [
        new ResponseInputMessage(ChatMessageRoles.User, "Now show a small example.")
    ]
});
```

`PreviousResponseId` and the `Conversation` property are alternative state mechanisms and cannot be combined in one request.

## Stream typed events

```csharp
using LlmTornado.Responses.Events;

using CancellationTokenSource cts = new(TimeSpan.FromSeconds(30));

await api.Responses.StreamResponseRich(
    new ResponseRequest
    {
        Model = ChatModel.OpenAi.Gpt41.V41Mini,
        InputString = "List three benefits of immutable data."
    },
    new ResponseStreamEventHandler
    {
        OnEvent = evt =>
        {
            if (evt is ResponseEventOutputTextDelta text)
            {
                Console.Write(text.Delta);
            }

            return ValueTask.CompletedTask;
        }
    },
    cts.Token);
```

The event model also includes function-call argument deltas, reasoning events, tool lifecycle events, completion, failure, and incomplete states. Treat argument deltas as partial JSON; wait for the corresponding done event before executing a function.

## Responses through Chat

`ChatRequest.UseResponseEndpoint = true` explicitly selects Responses for a compatible OpenAI model. LlmTornado also selects Responses automatically when a model advertises Responses support but not Chat support. This lets `Conversation` and Agents use Responses-only models while keeping the higher-level programming model.

For the supported Codex pattern, see [Codex model routing](/advanced-and-preview/codex-routing).
