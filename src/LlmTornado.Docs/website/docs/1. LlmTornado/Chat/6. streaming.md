# Chat streaming

`Conversation.StreamResponseRich` delivers provider output through a `ChatStreamEventHandler` while appending the completed assistant message to the conversation.

## Stream text

```csharp
using LlmTornado.Chat;
using LlmTornado.Chat.Models;

Conversation conversation = api.Chat.CreateConversation(new ChatRequest
{
    Model = ChatModel.OpenAi.Gpt41.V41Mini
});

conversation.AddUserMessage("Explain async streams in three bullets.");

using CancellationTokenSource cts = new(TimeSpan.FromSeconds(30));

await conversation.StreamResponseRich(
    new ChatStreamEventHandler
    {
        MessageTokenHandler = text =>
        {
            Console.Write(text);
            return ValueTask.CompletedTask;
        },
        OnUsageReceived = usage =>
        {
            Console.WriteLine($"\nTotal tokens: {usage.TotalTokens}");
            return ValueTask.CompletedTask;
        }
    },
    cts.Token);
```

`MessageTokenHandler` receives text chunks, not guaranteed single tokens. Use `MessageTokenExHandler` when token index and other extended information are needed. Other modality callbacks include `ReasoningTokenHandler`, `AudioTokenHandler`, `ImageTokenHandler`, and `MessagePartHandler`.

## Observe streamed function calls

`FunctionCallDeltaHandler` fires while a provider's streamed tool request is being assembled:

```csharp
await conversation.StreamResponseRich(new ChatStreamEventHandler
{
    FunctionCallDeltaHandler = update =>
    {
        Console.WriteLine(
            $"call={update.CallId}, name={update.Name}, " +
            $"delta={update.ArgumentsDelta}, complete={update.IsComplete}");

        return ValueTask.CompletedTask;
    },
    FunctionCallHandler = calls =>
    {
        foreach (FunctionCall call in calls)
        {
            // Validate arguments, execute the approved function, then set call.Result.
        }

        return ValueTask.CompletedTask;
    }
});
```

`ArgumentsDelta` is only the newest fragment; `ArgumentsSnapshot` is the accumulated value known at that point. Both may be incomplete JSON. Use delta events for progress or UI only, and execute the tool from `FunctionCallHandler` after assembly completes.

The shared callback is populated for supported OpenAI-compatible, Anthropic, Google, and Cohere streams. Provider event shapes still differ, so do not assume that every field arrives in the first delta.

## Responses events through Chat

When Chat routes a request through the Responses endpoint, `OnResponseEvent` exposes the underlying typed event as well as the shared high-level callbacks:

```csharp
await conversation.StreamResponseRich(new ChatStreamEventHandler
{
    MessageTokenHandler = text =>
    {
        Console.Write(text);
        return ValueTask.CompletedTask;
    },
    OnResponseEvent = evt =>
    {
        Console.WriteLine(evt.EventType);
        return ValueTask.CompletedTask;
    }
});
```

Use [the Responses API](/llmtornado/responses/overview) directly when Responses-specific event types are the main abstraction.

## Completion, errors, and cancellation

- `OnFinished` receives finish metadata after a successful stream.
- `OnUsageReceived` receives provider usage when available.
- `HttpExceptionHandler` handles HTTP-level failures when configured.
- `OnSse` exposes raw server-sent events for diagnostics.
- The `CancellationToken` stops establishing or consuming the stream.

UI applications should marshal callbacks onto their UI thread and batch rapid text updates when necessary.
