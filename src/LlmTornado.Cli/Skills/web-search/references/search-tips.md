# Search Query Tips

## General
- Be specific: "Python asyncio timeout handling" > "python async"
- Use quotes for exact phrases: `"connection refused" docker compose`
- Exclude terms with minus: `rust tutorial -game`

## Operators (DuckDuckGo)
| Operator | Example | Effect |
|----------|---------|--------|
| `"..."` | `"exact phrase"` | Match exact phrase |
| `-word` | `python -snake` | Exclude word |
| `site:` | `site:stackoverflow.com async` | Search specific site |
| `filetype:` | `filetype:pdf machine learning` | Find specific file types |
| `intitle:` | `intitle:guide docker` | Word must be in title |

## Strategy for Technical Questions
1. Start with the error message (quoted) + technology name
2. If too few results, remove version numbers and simplify
3. If too many results, add the specific framework/library name
4. For "how to" questions, include the programming language explicitly

## Strategy for Research
1. Start broad to find key terminology
2. Narrow with specific terms discovered in initial results
3. Use `site:` to target authoritative sources (docs, wiki, papers)
