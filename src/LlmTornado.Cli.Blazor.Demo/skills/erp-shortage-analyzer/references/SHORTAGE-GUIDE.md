# Procurement Shortage Guide

## Approval Thresholds
| Total RFQ Value | Approval Required |
|---|---|
| < $5,000 | Auto-approve |
| $5,000 - $25,000 | Buyer Manager |
| $25,000 - $100,000 | Procurement Director |
| > $100,000 | VP Supply Chain |

## Quantity Break Guidelines
Always request these quantity breaks:
- **1x** — Exact shortage quantity
- **1.5x** — 50% buffer for demand uncertainty
- **2x** — Volume discount threshold
- **3x** — Bulk discount threshold

## Vendor Selection Rules
1. Always use the preferred vendor if one is assigned
2. For items without a preferred vendor, search for qualified vendors via web search
3. Never create an RFQ without at least one vendor quote target

## Lead Time Escalation
- **> 8 weeks**: Flag as "long lead" in RFQ notes
- **> 12 weeks**: Escalate to Procurement Manager via email
- **> 16 weeks**: Consider alternate sourcing or engineering change
